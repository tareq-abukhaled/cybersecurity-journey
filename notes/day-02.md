# Day 02 - Computer Fundamentals & Client-Server Basics

## Computer Systems

* Learned about the main components of a computer.
* Learned how a computer boots up, including how the bootloader is selected and how the operating system is loaded into RAM.

## Computer Types

Not every computer has a keyboard, mouse, or screen. Many devices we use every day are computers, including:

* Servers
* IoT devices
* Embedded devices

## Client-Server Model

* Learned the difference between a client and a server.
* Learned that the client initiates a request and the server responds.
* Learned how protocols define the way clients and servers communicate.
* Learned that ports identify specific services running on a system.
* Learned how DNS maps domain names to IP addresses.

## HTTP

* Learned that HTTP is a stateless client-server protocol used on the web.
* Learned that HTTP uses methods to define what the client wants to do.
* Focused on the `GET` method, which is used to request a resource from a server.
* Learned the basic idea of HTTP requests and responses.

## Browser Developer Tools

Used the browser's **Network** tab to observe HTTP requests happening behind the scenes.

Learned about:

* **Scheme** - The protocol being used, such as HTTP or HTTPS.
* **Host** - The host being requested.
* **Filename** - The requested file or resource.
* **Status Code** - Indicates the result of the request.

### Common Status Codes

* `200 OK` - The request was successful.
* `403 Forbidden` - Access to the resource is forbidden.
* `404 Not Found` - The requested resource was not found.
* `500 Internal Server Error` - The server encountered an error.
